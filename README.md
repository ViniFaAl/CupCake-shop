# 🧁 Cupcake Shop

## Sobre o projeto

O **Cupcake Shop** é um projeto acadêmico desenvolvido para a disciplina de Projeto Integrador Transdisciplinar em Engenharia de Software II.

O objetivo é desenvolver uma loja virtual de cupcakes com uma interface moderna, intuitiva e responsiva, facilitando a navegação e a experiência de compra dos usuários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Python
- SQLite
- Git e GitHub

## Funcionalidades

- Catálogo de cupcakes.
- Interface responsiva para dispositivos móveis e computadores.
- Menu de navegação adaptado para dispositivos móveis.
- Carrinho de compras com armazenamento local.
- Finalização de pedidos (checkout).
- Opções de retirada e entrega.
- Simulação de pagamento.
- Armazenamento de pedidos em banco de dados SQLite.
- Painel administrativo para gerenciamento de pedidos.
- Acompanhamento do status dos pedidos pelo cliente.

## Como executar o projeto

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Verifique se o Python está instalado.
4. Abra o terminal na pasta do projeto.
5. Execute o comando:

   `python server.py`

6. Abra o navegador e acesse:

   `http://127.0.0.1:8000/index.html`

**Observação:** o sistema precisa do servidor Python em execução para utilizar as funcionalidades relacionadas aos pedidos e ao banco de dados.

## Banco de dados

O projeto utiliza SQLite para armazenar os pedidos.

O arquivo local do banco de dados não é enviado ao GitHub, conforme as configurações do `.gitignore`.

## Objetivo acadêmico

Aplicar conceitos de Engenharia de Software, desenvolvimento web, interface e usabilidade, integração entre frontend e backend, persistência de dados e testes de software.
